# 中文听写程序

一个基于 Web 的中文听写练习工具，使用微软 Edge TTS 语音合成，无需安装任何额外的语音引擎或浏览器插件。

## 功能特点

- 🎙️ **高质量语音** — 基于 Microsoft Edge TTS（XiaoxiaoNeural），自动生成标准普通话发音
- 🌐 **纯网页交互** — 启动后自动打开浏览器，在手机、平板、电脑上都能使用
- 📁 **词汇表管理** — 将 `.txt` 文本文件放入 `words/` 目录即可作为听写词库
- ⏱️ **智能间隔** — 每个词语朗读两遍，自动根据字数计算书写等待时间，不足 3 秒自动延长
- 🔊 **倒计时提示音** — 每个单词倒计时最后三秒发出短促提示音，提醒学生注意下一个生词
- 📊 **听写回顾** — 完成后以网格形式展示全部词语，方便核对批改
- 🖥️ **WSL 支持** — 自动检测 WSL 环境并调用 Windows 浏览器打开页面

## 安装

本项目使用 [uv](https://docs.astral.sh/uv/) 管理依赖：

```bash
uv sync
```

或直接通过 pip：

```bash
pip install edge-tts rich requests
```

## 使用方法

### 1. 准备词汇表

在项目目录下创建 `words/` 文件夹，放入任意数量的 `.txt` 词汇表文件，每行一个词语：

```
words/
├── 一年级上册.txt
├── 一年级下册.txt
└── 成语积累.txt
```

词汇表示例：

```text
天空
大地
花草
树木
一心一意
```

### 2. 启动服务

```bash
python main.py
```

程序会自动启动本地 Web 服务（默认端口 `8765`），并尝试打开浏览器。

### 3. 开始听写

1. 在页面中选择要听写的词汇表
2. 首次使用会自动下载生成语音文件，稍等片刻
3. 点击屏幕开始听写：每个词朗读 **两遍**，随后倒计时供书写
4. 倒计时最后 3 秒会发出短促提示音，提醒学生下一个词即将开始
5. 听写结束后再次点击屏幕，即可查看全部词语

## 配置说明

在 `main.py` 顶部可修改以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `WORDS_DIR` | `./words` | 词汇表文件夹路径 |
| `AUDIO_DIR` | `./audio` | 音频缓存文件夹路径 |
| `INTERVAL_1` | `1` | 两遍朗读之间的间隔（秒） |
| `INTERVAL_2` | `1` | 每个字符的书写等待时间（秒） |
| `INTERVAL_3` | `0` | 额外等待时间（秒） |
| `WEB_PORT` | `8765` | Web 服务端口 |
| `TTS_VOICE` | `zh-CN-XiaoxiaoNeural` | TTS 发音人 |
| `TTS_RATE` | `-30%` | 语速调整（负数为减速） |

```
└── README.md        # 本文件
```

## 依赖环境

- Python >= 3.13
- 网络连接（首次生成语音需联网调用 Edge TTS 服务）

## 技术栈

- **后端**：Python `http.server` + `edge-tts`
- **前端**：原生 HTML / CSS / JavaScript（零构建、零框架）
- **终端**：`rich` 彩色输出
